Complete ExamShuffle Pro User Guide

Step-by-step instructions for preparing, randomizing, presenting, checking, and exporting examinations.

Before you begin

  • Open this HTML file in a modern browser such as Chrome, Edge, or Firefox. Most functions run locally in the browser.
  • Work through the numbered tabs in order when preparing a new examination.
  • Your questions, header details, logo links, and generated versions are saved in this browser's local storage. This is not cloud synchronization; another browser or device has a separate copy.
  • Keep a separate backup of important question banks and exported examinations. Clearing the cache removes this application's saved state.

1. Exam Details

Enter the school name, department, examination title, subject, teacher/instructor, term or school year, and general instructions. Check the Header Preview while you type; it reflects the details that will appear on the examination.

Left-Side Logo: paste a direct, publicly accessible image URL into the left logo field. This image appears on the left of the header, close to the heading text. Right-Side Logo: paste a separate direct image URL into the right logo field. Either logo can be used independently. PNG, JPG/JPEG, SVG, and WebP are common supported formats, subject to the image host's permissions.

If a logo does not appear, check that the URL points directly to an image and that the host allows the browser to load it. Review the printed preview before exporting.

2. Upload / Input Questions

Use the question-input tools available in this section to add questions manually or import supported content. Follow the format and file-type notes shown on the page. After importing, confirm that the questions, choices, question types, and correct answers were interpreted correctly before continuing.

If text parsing is available, review the parsed result carefully; unusual formatting in a source document may require manual correction. Do not assume an imported answer key is correct until you verify it.

3. Review & Edit Items

Inspect the full question bank. Edit question wording, select the correct question type, update choices, set the correct answer, add or remove choices where applicable, and delete questions that should not be included. Recheck numbering and answer keys after editing.

Question types may include multiple choice, true/false, and identification. Use the fields provided for the selected type. Keep multiple-choice options distinct and ensure that the correct answer matches one of the displayed choices.

4. Randomize & Export

Use the randomization controls to shuffle the current question set and, where enabled, the answer choices. Choose the number of versions before generating multiple versions. Review each generated version using the version selector/tabs and confirm that the question order and answer key remain correct.

Use the available export controls to produce the supported output format, such as a Word document. Check the exported file before printing or distributing it. If an answer key is included, make sure the setting matches your intended output.

5. Classroom Mode

Open Classroom Mode when displaying questions to students on a projector or classroom screen. Use the previous/next controls to navigate, the timer controls to start, pause, or reset timing, and the text-size controls to improve visibility from the back of the room. Test the display before class begins.

6. Peer Checking Mode

Use Peer Checking Mode to guide students through checking responses. Choose the desired generated version, use the guided slide or grid view where available, adjust text size for readability, and reveal answers only at the appropriate point in the activity. Explain the checking rules before students begin and supervise score recording.

7. Quiz Bee Challenge

Load questions into Quiz Bee from the available exam version or question bank. Shuffle the questions if desired, set the team names, and begin the challenge. Navigate with Previous and Next Question. Keep the answer hidden while teams deliberate, then use Reveal Answer to display it. Award points to the appropriate team with the scoring controls. Use Reset Scores to restart the scoreboard when needed.

Agree on rules before starting—for example, how teams signal, how long they have to answer, and whether a missed question can be stolen. The scoreboard is an in-page activity aid, so record final results separately if they must be retained.

Top-bar controls and saving

  • Items: displays the number of questions currently loaded.
  • Full Screen: enters or exits the browser's full-screen mode. Your browser may require a user click and may provide its own exit hint; press Esc to leave full screen when supported.
  • User Guide: opens this guide. Use Close to return to the app.
  • Active Key: indicates the selected generated version when that indicator is visible.
  • Clear Cache: asks for confirmation, then removes this app's saved local state and restores its default sample questions and original header values. Use it only when you intend to reset the app.

Changes are saved automatically to the browser's local storage when supported. Avoid clearing browser site data if you need to retain your locally saved work.

Troubleshooting checklist

  • Logo missing: use a direct image link and test it in a new browser tab.
  • Wrong header or answers: return to Exam Details or Review & Edit Items and check the source fields before regenerating or exporting.
  • Export looks different: open the exported document and inspect page breaks, margins, images, and answer-key settings before printing.
  • Saved work is missing: reopen the file in the same browser profile and device where you made the changes; local storage is not shared between devices.
  • Full screen does not start: click the button directly and allow the browser to perform the full-screen request.

Recommended workflow: enter exam details → add/import questions → review every item and answer → generate and inspect versions → export and proofread → use Classroom, Peer Checking, or Quiz Bee modes as needed.
